# 管理后台使用说明

README「管理后台」一节的展开版：后台页面构成、DNS 编辑双模式、设置页每个分区的开关、各字段取值上限、备份与恢复口径。部署与绑定项见 [`deploy.md`](deploy.md)。

## 后台入口

默认路径是 `https://你的域名/admin`；设置环境变量 `ADMIN_PATH` 后改为 `https://你的域名/<自定义路径>`。首次用 `ADMIN_PASS` 登录。

## 后台主要页面
- **仪表盘**：展示请求量、流量趋势、资源类别、运行状态、定时任务状态，按需手动刷新
- **节点管理**：搜索节点、导入/导出配置、单节点或全局 GET 健康探测
- **日志记录**：按日期范围查询请求记录、初始化 DB、手动清理
- **DNS 编辑**：当前站点 DNS 草稿编辑、推荐优选域名、DNS 历史记录回填、优选 IP 工作台与抓取源、实用链接
- **设置页**：系统 UI、DNS 设置、代理与网络、静态资源策略、安全防护、日志设置、监控告警、账号设置、备份与恢复

## DNS 编辑页说明

- 后台 DNS 编辑页内置 **推荐优选域名** 卡片，点击后会自动回填当前站点的 `CNAME` 草稿，但仍需要再点一次“保存 DNS”才会真正写入 Cloudflare
- `CNAME模式`：只保留 1 条 `CNAME`；保存时会自动删除当前站点下的 `A / AAAA`
- `A模式`：可混合多条 `A / AAAA`，最少保留 1 条；切换到该模式时只会先改后台草稿，不会立刻改 Cloudflare
- 从 `A模式` 切回 `CNAME模式` 时，如果当前没有有效 CNAME 草稿，会默认回填 `saas.sin.fan`
- DNS 历史记录只保留 `CNAME` 修改历史，点击历史卡片会自动切回 `CNAME模式` 并回填内容
- 实用链接分两组：优选域名（`CM优选域名集合`、`NB优选`、`VPS789 域名优选`）与优选 IP（`VPS789 优选IP`、`Wetest IPv4 优选`）
- **优选 IP 工作台**：共享快照存在 D1（`dns_ip_pool_*`），浏览器本地「独立 IP 池」只存在本机；勾选后可回填 `A / AAAA` 草稿（需先开启「仅显示当前站点」），删除会同时清理共享快照与本地池
- **优选 IP 抓取源**：下拉顺序固定为「自定义输入 → 内置来源（`麒麟优选`、`CF-SPEED-DNS优选`）→ 优选预设（Wetest v4 / v6、VPS789、164746、haogege、bestcf）」，抓取结果写 D1 共享快照，本地池用「导入独立 IP 池」
- **探测**：按当前管理请求入口的 BGP 路由，探测目标 IP 命中的 Cloudflare COLO，结果有缓存复用；等待时间限制在 1000–180000 毫秒

## 设置页中可直接配置的能力

> 默认进入 **新手模式**，设置页只隐藏「代理与网络」和「安全防护」两栏，其余分区（含静态资源策略）都会显示。切换到 **高手模式** 后才会出现这两栏，并展开更细的日志调优 / KV 修复工具与高级字段。

- 协议策略档位（`compat` 兼容优先 / `balanced` 均衡优先 / `aggressive` 激进优先）

  - `balanced`：启用 HTTP/2、HTTP/3，但在 UTC+8 的 20:00–24:00 晚高峰降级到 HTTP/1.1

- 403 重试与协议回退
- 路由控制（`routingDecisionMode`：与主视频流策略一起决定哪些请求直连、哪些走 Worker）
- 轻量级元数据预热
- 元数据预热缓存时长
- 预热深度（仅海报 / 海报+索引）
- 预热预取字节数（默认 4 MiB，最高 8 MiB）
- 静态文件直连

- HLS / DASH 直连命中时，播放列表与分片自动走 307 数据面直传

- PlaybackInfo 缓存开关与缓存时长（0–60 秒）
- 视频回传进度开关与上报间隔
- 故障转移探测（`hedge*` 组：探测路径、超时、并行度、等待时长、锁 TTL、偏好 TTL、失败冷却、抖动）

- 一键恢复推荐值

### 备份与恢复
- 保留一代设置快照：每次保存设置前，当时的配置会整份写进 `sys:config_theme_prev:v1`。面板上的「恢复上次配置」按钮会二次确认后把它写回去，恢复动作本身也留快照，所以连点两次能来回切。升级后的第一次保存才开始有快照，此前的历史只剩导出文件
- 旧版的多代设置快照（`sys:config_snapshots:v1`）仍然下线，KV 整理会删掉检测到的遗留键
- 面板上的「迁移与备份」只保留一组入口：「导出完整备份」与「导入备份」。settings-only 的 `exportSettings` / `importSettings` 接口仍然存在，但不再有面板按钮；直接调接口时同样是整体替换当前 settings，未包含字段回退为默认值（密钥与管理端皮肤保留当前值），带 `includeSecrets` 导出要 `X-Admin-Confirm` 头
- 「导出完整备份 / 导入备份」（节点 + 全局设置 + 管理端 HTML）；备份里的 `config` 是空对象时按「没有配置」处理，不会把设置刷回默认：备份里的 HTML 会作为新的管理端 revision 写回 KV 并立即启用；备份引用的 revision 既不在文件里也不在当前 KV 时，整次导入以 `ADMIN_INDEX_BACKUP_MISSING` 拒绝，不会半途覆盖
- 完整备份导入前会弹一次预览确认（节点数、设置字段数、是否含 HTML 与明文密钥），请求体上限 12 MiB；超过上限请到节点列表单独导出节点、精简后再导入
- 节点列表页的「导出节点配置 / 导入节点」是独立通道：导出直接读 `node:*`，不受完整备份的大小闸门限制；导出的节点文件含上游凭据（`secret` / `headers`），跟完整备份一样请只放在可信位置
- 单独导入节点与完整备份导入都会在写 KV 前整批校验节点资源上限，任一节点超限则整批拒绝
- 一键整理 KV / D1 数据（高手模式；先生成预览，再使用签名计划执行；CRON 每小时自动兜底）
- 同一分区里还有「Worker 和 HTML 更新」卡片：要同时选一个 Worker 脚本（任意 `.js`）和一个管理台 HTML（任意 `.html`）才会启用，两个文件必须来自同一版本；只上传单个 HTML 走首次启动的上传页或 `?setup=1`（上限 2 MiB）

### 设置保存的防重置闸门
- 保存设置时，服务端会把本次载荷和 KV 里的当前配置逐字段比对；如果一个请求里有 **8 个以上** 字段从「非默认值」退回「默认值 / 空」，就判定为疑似整份重置，返回 `CONFIG_MASS_RESET_BLOCKED` 并且 **不写入**。
- 管理台收到这个 409 会弹一次确认框，列出被重置的字段名（只给字段名，不给值），确认后带 `confirmMassReset: true` 重发同一个请求；取消就什么都不写。导入备份（`importSettings` / `importFull`）和「一键整理 KV」不受这条闸门限制。
- 管理台在拿到配置之前不允许写配置：`saveConfig` / `importSettings` / `importFull` / `tidyKvData` 在 `runtimeConfig` 还没水合（字段数不到 20）时会被本地拦下，顶部出现「全局配置尚未加载完成」横幅，皮肤开关这类操作直接不发请求。这条是为了 2026-11-04 那类事故：`getAdminBootstrap` 卡住近 90 秒，期间点皮肤把一份只有 `adminUiSkin` 的载荷写进 KV，服务端用默认值补齐，整份配置被重置。

### 全局设置上限说明
- 元数据预热缓存时长：0 到 3600 秒；只作用于 `m3u8 / 字幕` 等轻量索引，不直接缓存视频主字节流。
- 预热深度：当前支持“仅预热海报”和“预热海报+索引”两档。
- 预热预取字节数：0 到 8388608 字节；默认 4194304 字节（4 MiB），用于限制单次后台预热的累计读取预算。
- 静态资源缓存时长：0 到 365 天，统一作用于海报、封面、字幕及前端静态资源策略入口。
- HLS / DASH 直连与元数据预热联动：开启“HLS / DASH 直连”后，命中的播放列表与分片直接走 307 数据面直传；海报与字幕仍可按当前策略预热。
- Cloudflare Cache Rules：建议在视频路径上额外配置 “Ignore query string”，让不同用户的不同 Token 指向同一缓存实体。
- Ping 超时 / 上游握手超时：最高 180000 毫秒。
- 额外重试轮次：最高 3 次，避免额外消耗 Worker 子请求预算；Cloudflare 官方限制每次请求的子请求数量存在平台上限，免费计划与付费计划的额度不同。
- D1 单批写入切片大小：最高 100 条，避免单批过大。
- 定时任务租约时长：30000 到 900000 毫秒；对应 Cloudflare Cron 单次最长 15 分钟的官方限制。
- 设置变更历史：只保留一代（`sys:config_theme_prev:v1`，每次保存前写入，KV 整理保留）。`sys:config_snapshots:v1` 是旧版遗留键，保存设置与 KV 整理都会删除它；更早的历史只能依赖导出的备份文件。
- 全局设置专用迁移：导入时会整体替换当前 settings，适合多环境同步；旧字段会先做兼容清洗，再按当前字段模型落盘。

## 节点配置资源上限
- 单个节点序列化后最多 256 KiB，最多包含 32 条线路。
- 自定义请求头最多 64 个、总计最多 64 KiB；单个请求头名称最多 128 字节，单个值最多 8 KiB。
- `displayName`、`remark`、`tag`、颜色、密钥、Host 前缀目标、探测路径、标签项以及线路 `id / name / target` 等单项文本最多 4 KiB。
- 新增、保存或导入超限节点时返回 `NODE_RESOURCE_LIMIT_EXCEEDED`；批量导入会在写 KV 前整批校验，任一节点超限都不会产生部分写入。
- 旧版本遗留的超限节点仍可读取和代理，管理端会明确警告，但 Worker 不会把它放入节点 / 播放路由热缓存，也不会在整理时自动回写。
