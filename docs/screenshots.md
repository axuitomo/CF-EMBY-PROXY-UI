# 页面截图索引

仓库里唯一存在的管理后台截图是 `tests/e2e/visual.spec.mjs-snapshots/` 下的 10 张 Playwright **视觉基线**。它们不是发布宣传图，也不是「当前 UI 该长什么样」的权威参考，而是防样式漂移的比对底片。这份文档给每张图建索引：哪个视图、哪套主题、什么时候录的、图上能看到什么、对应哪一节文档，以及哪些视图根本没有图。

录图机制与像素容差的说明在 [`tech-stack.md`](tech-stack.md) 的「视觉基线」段和 [`development.md`](development.md) §7.1，这里只做索引，不重复。

## 图本身暴露的四件事

1. **所有数值都是空库状态。** e2e 每次跑前清空 `.wrangler/e2e`，所以仪表盘显示 `未配置` / `缓存命中` / `节点索引: 已加载` / `待记录`，节点与日志是「暂无匹配」，请求趋势没有数据点。这些图能验布局和配色，**不能当数据示例看**。
2. **DNS 页在这套基线里是半残的。** 没有真实 Zone ID 与 API 令牌，卡片直接显示「当前站点：加载失败」，A 模式、优选 IP 工作台、DNS 历史卡片都没有出现在图里。
3. **设置页只露了新手模式的样子。** 左侧导航只有 7 项（系统 UI、DNS 设置、静态资源策略、日志设置、监控告警、账号设置、备份与恢复）；「代理与网络」「安全防护」只在高手模式出现，图上没有。
4. **旧的设置页截图带着过时文案。** V19.9 那张的「设置操作视图」说明写着新手模式会隐藏「静态资源策略分区」，但同一张图的导航里静态资源策略是可见的，当前 [`panel.md`](panel.md) 也明确说新手模式只隐藏两栏。这说明该图录于旧文案，**引用这张图时不要抄它的说明文字**。

## 重录与比对

```bash
npx playwright test tests/e2e/visual.spec.mjs --update-snapshots   # 重录基线
npx playwright test tests/e2e/visual.spec.mjs                      # 与基线比对
VISUAL_MAX_DIFF=0 npx playwright test tests/e2e/visual.spec.mjs    # 排查时看全量差异
```

- 默认容差 0.2%（`maxDiffPixelRatio`），来自字体抗锯齿抖动；差异图落在 `test-results/**/*-diff.png`。
- 文件名带 `-win32` 平台后缀，换操作系统就没有可比基线，所以这项**不进 `npm run check`、不进 CI**。
- 要重录就整组重录：现在这批图混着三个版本，只补一张会让「哪张代表当前 UI」更难判断。重录后在同一个提交里更新上面的版本徽标与录制时间两列。
- 上面「没有截图」表里列缺口，是重录时可以顺手补齐的清单；补了哪张就把它从缺口表挪进索引表。
